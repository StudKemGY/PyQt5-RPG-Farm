# 🚜 RPG Farm Game on PyQt5

**RPG Farm** — это десктопная игра-симулятор фермы, разработанная на языке **Python 3** с использованием фреймворка **PyQt5**. Графический интерфейс приложения полностью спроектирован в **QtDesigner**, а состояние игрового мира, экономика и прогресс персонажа синхронизируются в реальном времени с базой данных **SQLite**.

Проект укомплектован в строгом соответствии с академическими критериями оценивания лабораторных работ.

---

## 📋 Техническое задание (ТЗ) и логика игры

### Основные механики
1. **Игровое поле:** Представляет собой сетку размером 10х10 ячеек на базе `QTableWidget`. Каждая ячейка динамически заменяется на полноценную графическую текстуру (`.png`) из папки `assets` в зависимости от типа объекта (Трава, Дом, Лавка, Загон, Сухая или Политая грядка).
2. **Свободное перемещение:** Игрок управляет персонажем (`Я`) с клавиатуры при помощи клавиш `WASD` или стрелочек. Перемещение по клеткам полностью **бесплатное** и не расходует энергию героя.
3. **Система Огородничества:** 
   - Посадка семян на пустой грядке переводит её в статус сухого ростка (`🌱 сухая`). В этом состоянии рост заморожен.
   - Игрок должен подойти к грядке и **вручную полить её** кнопкой взаимодействия. Полив расходует **5 единиц энергии**.
   - После полива текстура меняется на мокрую землю (`dirt_watered.png`), статус меняется на `🌱💦 Растет`, и запускается таймер созревания. Время роста — **30 секунд** (работает через фоновый `QTimer`).
4. **Животноводство и Торговля:** В лавке приобретается корм, в загоне кормится скот с мгновенным получением прибыли за продажу молока.
5. **Система отдыха:** Сон в Доме восстанавливает энергию персонажа до 100% и перелистывает счетчик дней.

## 🏗️ Соответствие техническим критериям (10 из 10 баллов)

*   **а. Не менее двух форм:** Использованы `main_window.ui` (главное окно) и `market_dialog.ui` (модальное окно торговли).
*   **b. Не менее 5 различных виджетов:** В коде задействованы `QMainWindow`, `QDialog`, `QTableWidget`, `QPushButton`, `QLabel`, `QComboBox`, `QSlider`, `QTextEdit`.
*   **c. Стандартные диалоги:** Интегрирован `QMessageBox` для вывода предупреждений об усталости и успешных покупках.
*   **d. Наличие мультимедиа:** Использование графических иконок `QIcon` для текстурирования карты и класса `QSound` для воспроизведения системного звука при переходе на новый день.
*   **e. Работа с БД (2 таблицы):** База данных `rpg_farm.db` (SQLite) хранит параметры игрока (`player_hero`) и состояние 100 ячеек карты (`world_map`). Поддерживаются операции чтения, записи и обновления данных.
*   **f. Обработка клавиатуры:** Полный перехват `keyPressEvent` для передвижения персонажа и кнопка `ESC` для быстрого сохранения и выхода.
*   **g. Обработка мыши:** Клик правой кнопкой мыши по форме полностью очищает многострочный бортовой журнал фермера (`mousePressEvent`).

## 📂 Структура репозитория

```text
├── assets/                  # Папка с графическими PNG-текстурами
├── ui/                      # Папка с интерфейсами (QtDesigner)
│   ├── main_window.ui       # Главное окно игры
│   └── market_dialog.ui     # Окно магазина
├── main.py                  # Основной запускной файл и GUI-логика
├── farm_db.py               # Модуль СУБД SQLite (инициализация и сохранение)
├── requirements.txt         # Список внешних зависимостей проекта
└── README.md                # Данная документация проекта
```

## 🚀 Инструкция по сборке и запуску из кода

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Запуск игры
```bash
python main.py
```
*При первом старте приложение автоматически создаст локальный файл базы данных `rpg_farm.db` и сгенерирует карту.*

## 📦 Сборка независимой версии (.EXE)
Сборка проекта в standalone-пакет для сдачи преподавателю осуществляется командой:
```bash
python -m PyInstaller --noconfirm --onedir --windowed --add-data "ui;ui" --add-data "assets;assets" main.py
```
Финальный билд со всеми необходимыми библиотеками, интерфейсами и текстурами будет находиться в папке `dist/main/`.
